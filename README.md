# throw
An app to track pottery sessions.

## Exploring Accessibility in the app

Search for "DEMO TOGGLE" in ViewControllers to toggle between accessible and inaccessible versions of components

### Reusable Components
Below is a list of reusable components and classes that may be useful in development:
- `AccessibleTextField.swift` for creating textFields that alter their focus box
- `LabeledTextField.swift` for creating textFields with labels and enlarged focus box
- `UIFont+DynamicType.swift` for supporting dynamic type with custom fonts
- `SwitchTableViewCell.swift` for creating TableViewCells with controls that are actionable
